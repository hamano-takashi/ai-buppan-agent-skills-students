# AI×物販 受講生向け AIスキル集

商品の企画、Amazon運用、画像制作、顧客対応、分析をCodexで進めるための教材です。講師の実務用スキルから個別情報と内部環境への依存を取り除き、受講生向けのルールを整えています。

## はじめ方

1. 講師から案内されたGitHubアカウントで、この非公開リポジトリを開きます。
2. Code メニューの Download ZIP から取得し、Windowsは「すべて展開」、MacはZIPを開いて展開します。Gitを使う方はクローンでも構いません。
3. 展開したフォルダをCodexの作業フォルダとして選びます。隠しフォルダの .agents も必要です。移動するときはフォルダ全体を扱ってください。
4. [安全に使うための注意](SECURITY.md)を読み、[事業情報のひな形](templates/project-context.md)を自分の local/project-context.md にコピーして必要な欄だけ記入します。個人情報・認証情報は記入しません。
5. [用途別の案内](docs/START_HERE.md)から行いたい仕事を選び、Codexへ依頼します。

事前のAPIキー設定、一括インストール、グローバル設定の変更は不要です。Codex自体の利用環境は各自で用意してください。画像生成や外部連携はアカウント・プラン・環境により利用できる機能が異なります。

## 何が入っているか

- [AGENTS.md](AGENTS.md): 安全、資料確認、品質、承認、画像生成の共通ルール。
- [SKILLS_INDEX.md](SKILLS_INDEX.md): 収録スキルと用途の一覧。
- .agents/skills/: スキル本体と専門分野の参照資料。
- [templates/](templates/): 自分の事業情報・画像依頼・作業ログのひな形。
- [docs/DISTRIBUTION.md](docs/DISTRIBUTION.md): 講師向けの更新・招待・配布手順。
- [docs/RELEASE_REVIEW.md](docs/RELEASE_REVIEW.md): 配布版の変更点、点検内容、未検証事項。

## 使い方の要点

自分の商品・対象期間・確認したいことを伝え、必要な資料を指定します。スキル名を暗記する必要はありません。特定のスキルを使いたい場合は SKILLS_INDEX.md の名前を指定してください。候補に表示されないときも、一覧から該当の SKILL.md を読むよう依頼できます。

画像生成・編集は、image2.5やimage2という指定なしでもCodexの組み込み画像生成を標準で使います。内部モデル名の固定を保証するものではありません。

個別資料や完成物は local/ へ置きます。この教材の共有GitHubへアップロードしないでください。講師への提出は講座で指定された方法を使います。

## 既存の配布版を使っている方へ

既存フォルダへ上書きせず、別フォルダで開いてください。以前のAPIキーや設定ファイルを丸ごとコピーする必要はありません。同じ名前のスキルをグローバルに入れている場合、候補が重複することがあります。このフォルダ内のスキルを選び、変更が反映されないときはCodexを再起動します。

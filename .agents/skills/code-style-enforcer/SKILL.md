# コード形式の確認

対象プロジェクトの AGENTS.md、README、設定ファイルと既存コードから規約を確認する。存在しない講師環境の規約を読み込まない。
新規JavaScriptは原則ES modulesを使う。既存の方式変更を依頼なく一括実行しない。
Python等にJavaScriptの規則を適用しない。認証情報を直書きせず、必要最小限の依存関係と明確なエラー処理を用意する。
変更箇所の型・構文・テストを実行し、未実行を合格扱いしない。

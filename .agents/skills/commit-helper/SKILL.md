# コミット前確認

1. git status と差分で、今回の変更と他の作業を分ける。
2. 認証情報や個別業務資料を含めない。秘密らしいファイルは中身を表示せず除外する。
3. 変更に必要な検証を実行する。Pythonは該当テスト、TypeScriptはプロジェクトの型検査など、実際にあるコマンドを使う。
4. 明示したファイルだけを追加し、ステージ済み差分を確認する。広範囲の一括追加を避ける。
5. 利用者の依頼範囲でコミットする。push、公開範囲変更、他者の履歴の書き換えは別の影響として扱う。

この配布教材の更新は tools/validate_distribution.py と tools/test_validate_distribution.py で確認する。

# コンバージョンLPの「ゼロから作る」方法論（DRM作成層）

> ec-lpo の補完リファレンス。本体(SKILL.md)が「既存LPを CV vs 非CV のセグメント比較で最適化する」のに対し、
> 本書は「売れるLPをゼロから設計・制作する」作成層を扱う。ダイレクトレスポンス(DRM)の正攻法に基づく汎用知識。
> ※ 固有名詞・クライアント案件データは一切含めない（汎用方法論のみ）。誇大・虚偽・優良誤認は景表法/特商法に配慮（捏造実績・根拠なきNo.1は書かない）。

---

## 0. 核心原則（これを外すと全部ダメ）

1. 集客成果 =「アクセス（知ってもらう）× 成約率（買ってもらう）」の掛け算。 まず成約率＝売れる状態（LP）を作る。認知・フォロワー・PVを先に追っても、買える状態がなければ集めたアクセスは全部ムダ（＝穴の開いたバケツに水）。成約率が先、集客は後（or同時）。
2. 最重要ページはLP。 全アクセスがLPに集まり、LPがアクセスをお金に変える「変換器」「ネット上の営業マン」「玄関」。
3. ホームページ(HP)では売れない。 HPは“信頼確認用”（実在性・安心の確認）。集客販売目的では機能しにくい。売るのはLP。
4. 狙うは「コンバージョンLP」。「デザインLP」ではない。 見た目の派手さ・世界観ではなく反応。良し悪しは見た目でなく反応（CVR・費用対効果・リスト獲得）で判断。正攻法でちゃんと売れる（嘘っぽい演出は不要）。
5. LPはまずコピー（文章）が主役、デザインは補助。
6. LP制作は販売のコア＝意思決定者（社長/できる担当）の仕事。「設計図」に基づいて作る。 丸投げしない。
7. 細部（ボタン文言・背景色・配置）でCVRは1.4〜2倍変わる。必ずA/Bテストで検証。
8. コンバージョンLPは資産。 一度作れれば長期間（1〜3年）使える。だから時間をかける価値がある。

---

## 1. やってはいけない「3つの間違い」（最初に潰す）

```
① 自己流で作る      → 独学・我流で迷走。改善も独断で時間がかかり売れない
② 競合の真似をする  → その競合が成功しているかは内部しか分からない。ダメを真似ると確実に売れない
③ 業者に丸投げ      → 業者の仕事はページ制作であって「商品を売る」ことではない
```

## 2. 制作の手順（設計図）

### A. 全体フロー
```
1. 売れるコンバージョンLPを作る（設計図ベース）
2. 広告でアクセスを集める（新規は Meta/Instagram 広告から）
3. 売る → 反応を見て 1日単位で予算を増減
```

### B. コピーの3手順（書く前提）
```
1. お客の「問題・悩み・願望」を徹底的に知る
2. それを解決するのが「この商品」だと特定する
3. それをどう伝えるか（コピー）を考える
```

### C. リサーチ4領域（コピーの土台）
```
商品 / お客（問題・悩み・願望・使っている言葉=VOC） / 競合（スワイプ） / 市場
※ 外注は事業主ほど対象を知らない → 売れるコピーは書けない。本気で外注するなら制作者がエンドユーザーに会う水準が必要。
```

### C-2. VOC収集プロトコル（「買う理由」のズレ検出・LP執筆前に必須）

```
大前提: 売り手が思っている強みと、お客が実際に買っている理由はズレる。
売り手は「品質・監修・実績・成分・サポート」を推したいが、お客は
「説明が難しくなくて安心した」「押し売り感がなかった」「自分みたいな人向けだと思えた」
「失敗しても傷が浅そう」「相談しやすそう」で買っていることが多い。
このズレを放置してLPを作ると「綺麗にズレたLP」が完成する
（見た目◎・文章◎・特徴も書いてある・でも刺さらない＝売れない原因はLPの手前にある）。
売れる言葉は会議室ではなく、お客の声の中にある。
```

実購入者への5つの質問（アンケート・オンライン面談・対面。最初は1人でもよい）:
```
1. なぜ、うちの商品を買ったんですか？
   → 一番大事。売り手の想定購入理由と本音のズレが最も出る
2. 買う前に、何に悩んでいましたか？
   → ファーストビューで刺す言葉の源泉。お客が実際に使った言葉をそのまま使う方が強い
3. 買う前、他にどんな選択肢と迷いましたか？
   → 競合は同ジャンル商品とは限らない。「買わない」「自分でやる」「知り合いに頼む」
     「無料ツールで済ます」も全部競合
4. 購入後、何が一番変わりましたか？
   → 価値は機能でなく「変化」で伝える（何ができるか < 買った後どう楽になるか）
5. もし友人に紹介するとしたら、何と言いますか？
   → 自然な紹介文は売り込み感のないリアルな言葉＝LPコピーの原文に近い
```

ズレ検出の手順: ①売り手の想定強みを書き出す → ②5質問の回答を並べる → ③ズレていたら
LPの訴求軸は顧客の回答側に合わせる（想定強みを捨てる勇気）。
実例の型: 集客に悩むレストランの強み仮説は「メニューの充実」だったが、顧客に
「なぜ来店するか」を聞くと「テーブル間の距離が広く、隣を気にせず話せるから」だった。
売るべきは料理でなく居心地＝訴求軸の全面転換。LPでも同じことが起きる。

### D. 組み立て（ブロック構成）
```
・上から1ブロックずつ積む（いきなり縦長1枚を書こうとしない）
・一番上＝ファーストビュー。最重要は「見出し（ヘッドライン）＋仲間見出し（サブ）」
・見出しはLP全体の約1%だが最重要。続きを読むか決まる。悪いと8秒以内に離脱。
```

## 3. ターゲット設定（刺さるLPの前提）

- ターゲットは1人に絞る。 「誰でもいい」LPは刺さらず離脱が大きい。絞ると「自分のことだ」と刺さり、CVR・リピート・収益が上がり、獲得費用は下がる。
- 複数ターゲットがいるなら、ターゲットごとに別々のLPを作る（1枚で全員を狙わない）。これで「必要なときに必要な数だけ」集められる。
- 年代などを広く括らない（40代/50代/60代は別人。括ると誰にも刺さらない）。
- 見込み客を2軸で分ける：
  - 顕在（検索＝Google/Yahoo）：解決策を探す“今すぐ客”。少数で奪い合い・価格競争・広告費高騰になりやすい。
  - 潜在（SNS＝Instagram/Facebook）：暇つぶし層。「欲しいが今すぐとは思っていない」。大量にいて安く・比較されにくい → 基本はこちらを狙う。
- 潜在客には「まだ良さを知らないだけ」と捉え、コピーで良さを丁寧に教える。心理トリガーは他人（友達）の成果・体験（ビフォーアフター）。
- ターゲティング精度の目安：Facebook/Instagram（ピンポイント）> Google（ある程度）> Yahoo（広め）。属性＋反応行動データ＋類似配信（買った人に似た人へ拡大）。広告は小さく出してうまくいけば増やす。

## 4. ヘッドライン／ファーストビュー（最も時間をかける）

### 見出し3チェック（一瞬で伝わるか確認）
```
1. あなたが提供するものは何か
2. それはお客の生活をどう変えるか
3. なぜあなたから買う必要があるか
```

### 作り方
- 第一歩はターゲットを絞る → 絞った客に向けて作る。
- 短い商品説明テンプレ4種（1つ書ければOK）：
  1. 特定客向けの短い商品説明
  2. 権威者が推せる使用方法
  3. 望ましい結果に特化した“唯一の”カテゴリー
  4. 期間内に結果が出なければリスクを減らす約束（保証）
- 悪い見出し＝抽象的で誰にでも当てはまる／自社名だけ／内輪用語 → 8秒で離脱。

---

## 5. 本文・CTA・A/Bテスト

- 本文の型（例）：リード（問いかけ）→ チェック付き重要ポイント →「多くの人がやりがちな3つの間違い」→ 解決（この商品）→ ベネフィット → 証拠 → オファー → 保証 → 限定 → CTA → 追伸。
- 証拠はビフォー→きっかけ→アフターの落差＋実数（※自社で取得した事実のみ。捏造しない）。お客様の声・第三者評価。
- 購入ページは“誘惑（余計なボタン・リンク・メニュー）”を減らす（気が散ると買う目的を忘れてCVRが落ちる）。
- A/Bテストで実証された具体策（要素は1つだけ変えて検証）：
  - ボタン文言：心理的ハードルが低い方が勝つ（例「カートに入れる」＞「今すぐ始める」）。
  - 背景色：おしゃれより見慣れた色（白＝大手で見慣れた配色）が勝ちやすい。
- 費用対効果は具体金額で示す（例：広告費◯円・CVR1.4倍なら…）。

---

## 6. 集客との接続（LP単体で完結しない）

- LPは広告（Meta/Instagram・Google/Yahoo 等）からの受け皿。広告の訴求とLPのヘッドラインをメッセージマッチさせる。
- 媒体ごとに来訪者の状態（検索＝顕在／SNS＝潜在）が違う → 入口の訴求を出し分ける。
- 広告＝コストでなく投資（出さないより最終利益が増えるか）。広告＋LPは短期で成果が出やすい（運用型は出せばすぐ反応）。SNSのコツコツ運用は時間がかかる。

---

## 7. AIでの制作（コアは人間が握る・順序を間違えない）

- ヘッドライン・コピー案・画像の“量産／たたき台”にAI（ChatGPT＋Canva等）を使ってよい。`マジックレイヤー`等で要素を編集し、最重要要素を一番大きく。
- ただし本文・コピーのコアをAIに丸投げしない（売れなくなる）。リサーチ・ターゲット・大きな約束・オファーは人間が設計する。
- 順序の原則: AIに丸投げするのではなく「顧客の声をAIに渡す」。
  AIも外注ライターも、渡された材料をもとに文章を作る＝材料がズレていたら完成物もズレる。
  「高品質なサービスを伝えるLPを」と依頼すれば高品質“っぽい”一般論が返るが、実際の購入理由が
  「相談しやすそう」「小さく始められそう」なら、それはズレたLPになる。AIは悪くない。材料の問題。
```
人間が先にやること（材料づくり）        AIに任せること（加工）
├── 顧客の声を集める（C-2の5質問）      ├── LPの構成案を作る
├── 買った理由を整理する（ズレ検出）    ├── 見出しを複数出す
├── 買う前の悩みを言語化する            ├── セールスコピーのたたき台を作る
├── 商品の本当の強みを見つける          ├── 読みやすく言い換える
└── 誰に向けたLPなのかを決める          └── 訴求パターンを比較する
```

## レビュー用チェックリスト（作成・診断）

- [ ] 実購入者の「買う理由」（C-2のVOC5質問）に基づいているか。売り手の想定強みとのズレを検証したか（未検証なら「綺麗にズレたLP」リスクを明記）
- [ ] 感情起点の設計をしたか: 支配感情を1つ特定したか／実用と感情のベネフィットを分けて感情側を主役にしたか／敵役（共通の敵＝構造・慣習）はいるか（→ ec-drm [心理的な訴求の確認](../../ec-emotional-marketing/SKILL.md)。人は感情で買い論理で正当化する。「ぐっと来ない」LPは大抵、敵役か支配感情が不在）
- [ ] これは“コンバージョンLP”か（デザインLP・HPになっていないか）
- [ ] ファーストビューの見出しで、提供物／生活の変化／なぜあなたから が8秒で伝わるか
- [ ] ターゲットが1人に絞られ「自分のことだ」と思えるか
- [ ] 成約率を上げる作りか（認知狙いの構成になっていないか）
- [ ] コピーが主役か（デザイン過剰でないか）／リサーチ4領域に基づくか
- [ ] ベネフィットは“機能”でなく“結果”か／証拠（声・実数）は事実ベースか
- [ ] CTAは1つに絞り、余計な誘惑（リンク・メニュー）を減らしているか
- [ ] テストすべき要素（まず見出し、次にボタン・背景）が用意されているか
- [ ] 広告の訴求とメッセージマッチしているか
- [ ] 誇大・嘘の演出・捏造実績がないか（景表法/特商法。正攻法か）

# 心理トリガー活用ガイド（詳細）＋ 感情起点の広告設計術

> ec-drm SKILL.md Skill 4（LF8・後天的9欲求・10大心理トリガー）の詳細活用編。
> 後半は「支配感情」を起点にプロモーション/LPを設計する方法論（クレイトン・メイクピース系の
> 感情起点コピーの実務知見。DRM実務家の解説を匿名化して吸収・2026-07-04）。
> ※ 感情訴求は「実在する感情への共鳴」であり、捏造・煽動ではない。誇大・虚偽・優良誤認は
> 景表法/特商法違反（数値・実績は自社取得の事実のみ。出稿前に fact-check / legal-check 必須）。

---

## 1. 大前提: 人は感情で買い、論理で正当化する

- 実用・スペック・実利は「買った後の言い訳（正当化材料）」に使われる。買う決断そのものは感情。
- 原点の洞察（寄付DM）: 寄付は商品も実利も何も受け取らないのに大量のお金が動き続ける
  ＝人が買っているのは「気持ち」（感情の変化・満足・癒し）。実用面でなく感情面に照準を合わせる。
- 高額品ほど感情の純度が高い（高級筆記具・オーディオ・車・新築…実用では説明できない）。
  逆に理屈と実利だけで買われる商品はコモディティ＝価格競争行き。中小がそこで戦ってはいけない。
- B2Bも入口は感情: 検討の土台に乗る最初のきっかけは感情（担当者の関心・不満・憧れ）。
  決裁プロセスは後段の合理フィルターにすぎない。入口の訴求は感情でよい。
- 衝動が起きなければ検討にすら上がらない。衝動買いは悪ではなく、売り手が設計すべき対象。
- 実務逸話では、実利訴求から感情起点への転換で反応が桁違い（数倍〜十数倍）に変わった事例が
  繰り返し報告される（例: 古い金貨を「投資リターン」でなく「その金貨が生まれた時代への
  ノスタルジー」で売り直して急成長した米国のコインディーラー）。数字は逸話であり保証ではない。

## 2. 支配感情（Dominant Emotion）を特定する

ターゲットの中で最も強く渦巻いている感情（不満・不安・怒り・憧れ・ノスタルジー・誇り等）を
1つ特定し、プロモーション全体をそこに賭ける。

- 探し方: お客が口に出さない・本人も自覚していないレベルの感情に気づく。
  源泉は VOC（ec-lpo C-2 の5質問）・現場の会話・レビュー・お客が反応しているニュース。
- 言い当てられた人は「なんで分かったの」となり、以降の話を聞く体勢になる（ラポール）。
- 「みんなが何となく思っているが、大きな声では言わないこと」を最初に言語化するのが最強の入口。
- 会議室の想像で決めない（実データ・実声から拾う。Rule 2 データドリブン）。

## 3. 共感の型（商品の話をせず、つながる）

- いきなりセールスをしない。世間話の型で入る: 相手が今ムカついている/不安に思っていること
  （相手の関心事）を先にこちらから言う → 共鳴が起きる → その後のオファーは「仲間の提案」として聞かれる。
- 例: ガソリンを売るなら「最近ガソリン高いですよね。あの税金おかしくないですか」から入り、
  共鳴ができてから「ドコモポイント使えますよ」→ 自然に売れる。
- 条件: 話題は商品と地続きであること（ガソリンを売るのにAIの時事ネタはNG。つながっている不満だけが効く）。

## 4. 感情的ベネフィット（実用と分けて設計する）

ベネフィットは2軸に分解して両方書く。感情側が主役。

| 軸 | 中身 | 例 |
|---|---|---|
| 実用的ベネフィット | 楽になる・得する・速い・安い | リターン率、時短、機能 |
| 感情的ベネフィット（＋） | 自尊心・ステータス・特別感・かっこよさ・所属 | 「これを使っている自分が好き」 |
| 感情的ベネフィット（−解消） | エモーショナルリリーフ＝溜まった不満・フラストレーションが晴れる「すっきり」「癒し」 | ずっとモヤモヤしていたことが解消される感覚 |

- 設計質問: 「この商品はどんな気持ちを満たすのか／どんな気持ちを癒すのか」
- 表現は機能でなく感情を見せる（例: デジタルノートをスペックでなく「鉛筆の温かみのある書き味」の
  映像で見せる。スマホを チップ性能でなく「軽くてかっこいい」で買わせているのが実例）。

## 5. 共通の敵（Common Enemy）

物語に敵役がいないと感情が動かない。敵＝感情のガソリン。

- 読者が「なりたい姿」になれていない外部の原因を名指しする。
  自己責任論（あなたの努力不足です）は事実でも救いがなく、反応しない。
  人は自分の見たい現実を見る＝外部原因の提示は強く支持される（スケープゴートの心理）。
- 効果は3つ:
  1. 怒り・不満の矛先が定まり、感情エネルギーが結晶化する
  2. 話が分かりやすくなる（物語の型: 主人公 vs 敵）
  3. 売り手と買い手が「共通の敵に対する同盟」になる＝売る/売られるの対立関係が解消され、
     仲間の提案として買ってもらえる（敵の敵は仲間）
- 原稿診断: レビューで「ぐっと来ない」と言われる原稿は、大抵敵役が不在。
  敵を明示して対立構造を作るだけで反応が激変することがある。
- 有名な型: 新興ブランドが業界の巨人を名指しで挑発し続けて熱狂的ファン層を作る
  （挑戦者ポジショニング）。
- ガードレール（必須）:
  - 敵は「業界の構造・慣習・古いやり方・仕組み」に設定する。
    実在の特定企業・個人への攻撃は誹謗中傷・信用毀損・営業妨害リスク＝legal-check必須
  - 事実に基づかない敵設定（捏造・陰謀論）は禁止。検証可能な不満・構造のみ扱う
  - 政治・国籍・属性による分断煽りは使わない

## 6. 10大トリガーとの関係（組み合わせ方）

- 支配感情メソッドは10大トリガーの上位の設計方針: まず支配感情を決め、その感情を増幅する
  トリガーを選ぶ（怒り→共通の敵＋損失回避／憧れ→社会的証明＋権威／不安→保証＋権威 等）。
- 順序: ①支配感情で心を掴む（§2-3）→ ②感情的ベネフィットで欲しくさせる（§4）→
  ③トリガーで後押し（希少性・緊急性・保証）→ ④論理的正当化の材料（実数・証拠・比較）で締める。
  感情で引きつけた後に正当化材料を必ず置く（買った後の後悔・返品を防ぐのも売り手の仕事）。

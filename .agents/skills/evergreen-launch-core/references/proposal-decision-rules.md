# 提案の確認事項

- 課題はヒアリングで確認したものだけを書く。推測は仮説とする。
- 予算を抑える案と成果に必要な範囲を含む案を比較し、作業範囲・費用・前提を明記する。
- 回収期間は増分の限界利益から計算する。売上と利益を混同しない。入力が不足すれば未算定とする。
- 向いていないケースを示す。
- 意思決定者が懸念しそうな点と、確認資料・対応策を整理する。

数値は fact-check で確認する。費用・契約条件を利用者の承認なしに確定しない。

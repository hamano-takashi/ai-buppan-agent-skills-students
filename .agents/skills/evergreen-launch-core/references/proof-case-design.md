# 小さな検証の設計

目的、対象、比較条件、期間、必要予算、成功条件、中止条件、データの取得方法を先に書く。
施策前後で分母・計測方法・販売期間・在庫状況をそろえる。広告、価格、季節性が変わった場合は効果の断定を避ける。
売上だけでなく、販売個数、粗利益、運用工数、返品件数を確認する。仮説の効果を二重加算しない。
結果は利用者の local/ に残す。顧客の声や実績を対外使用するときは、本人の同意、期間、母数、条件を確認する。

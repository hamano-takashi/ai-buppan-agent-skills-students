# 継続する販売導線を設計する

この手法をすべての事業に強制しない。利用者の顧客、購入頻度、粗利益、対応能力、同意取得方法を確認する。

1. 商品で解決できる課題と提供範囲を、実際のヒアリング・商品仕様から整理する。
2. 常設販売、期間限定販売、併用を比較する。期間限定の理由がないのに残り時間や残数を演出しない。
3. 認知→理解→比較→購入→利用支援→継続購入の流れを作る。不要な配信や申し込み項目を増やさない。
4. リスト取得は目的と解除方法を明示し、媒体の規約と利用者の同意を確認する。
5. 顧客数、販売数、粗利益、運用費、解約・返品、必要工数を測る。根拠のないLTV延長や売上保証をしない。
6. 小さく検証し、開始条件・中止条件・評価期間を決めてから自動化する。

提案の書き方は [提案の確認事項](references/proposal-decision-rules.md)、実証の設計は [検証計画](references/proof-case-design.md) を使う。配信文章は ec-crm-review-panel、法令・規約は legal-check と platform-policy-check に通す。

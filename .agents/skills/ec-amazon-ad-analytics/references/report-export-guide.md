# レポートの書き出し方ガイド

このスキルで使うレポートを、どの画面から書き出すかをまとめたもの。

注意: 画面名・メニュー名は2026年8月時点のもの。Amazonの管理画面は変わることがあるため、見つからない場合は現在の画面のヘルプで確認する。AIには書き出したファイルだけを渡し、管理画面そのものを操作させない。

## 1. 検索用語（検索語）レポート

週次の除外・昇格の仕分けに使う。

- 場所: 広告コンソール → 測定とレポート → スポンサー広告レポート
- レポートタイプ: スポンサープロダクト → 検索用語
- 期間: 直近30日以上を推奨（短いと判断保留だらけになる）
- 形式: CSVまたはExcel

## 2. キャンペーンレポート

月次メンテ・期間比較に使う。

- 場所: 広告コンソール → 測定とレポート → スポンサー広告レポート
- レポートタイプ: スポンサープロダクト → キャンペーン
- 期間比較をしたい場合は、比べたい2つの期間で同じ条件のレポートを2本書き出す（日数を揃える）

## 3. ビジネスレポート（詳細ページ売上・トラフィック）

セッション・ユニットセッション率・全体売上との突き合わせに使う。

- 場所: セラーセントラル → レポート → ビジネスレポート → 詳細ページ 売上・トラフィック（子ASIN別）
- 広告レポートと同じ期間で書き出す
- 注意: ビジネスレポートの売上は税込、広告レポートは税別。比較時はズレがあることを前提に読む

## 4. 検索クエリパフォーマンス（ブランド登録者のみ）

狙う語の市場内シェア診断に使う。

- 場所: セラーセントラル → マーケティング → ブランド分析 → 検索分析タブ → 検索クエリパフォーマンス
- 「ASINビュー」を選び、子ASINを1つずつ入力して書き出す（親ASINでは表示されない）
- バリエーションが多い場合は、売れ筋の子ASINと、キーワードが変わるバリエーション（味違いなど）だけでよい。サイズ・容量違いは省略してよい
- 期間は月次で揃えると比較しやすい

## よくあるつまずき

- CSVが文字化けする: 開くときに文字コードをUTF-8に指定する。ExcelやGoogleスプレッドシートの「インポート」機能から開くと直ることが多い。AIに渡す場合は化けたままでも読めることがあるので、まず渡して「列の意味を説明して」と聞いてみる
- どのファイルか分からなくなる: ファイル名に「レポート名_期間」を入れて保存する（例: 検索用語_0701-0731.csv）
- 期間がバラバラ: 突き合わせるレポートは必ず同じ期間・同じ日数で書き出す

# 事業の前提をそろえる

AGENTS.md を読み、利用者が指定した自分の事業の資料だけを確認する。講師や他の受講生の事業数値を前提にしない。

1. 商品・販売先・顧客・期間・現在の売上と利益・予算・在庫・使える時間を確認する。
2. 実績、目標、仮説、未確認を分ける。数値には対象期間・税込税抜・送料や手数料の扱い・原本を添える。
3. 成長段階は売上額だけで決めず、商品需要、採算、供給能力、継続購入、運用体制で説明する。
4. 売上目標を訪問数×購入率×客単価に分け、必要な在庫・広告費・資金を確認する。率と分母・件数を対にする。
5. 達成期限と検証方法を利用者と決める。未確認の目標値を自動採用しない。

記録にはリポジトリルートの templates/project-context.md を利用し、個別情報は local/ に保存する。予算・契約の最終決定は利用者が行う。

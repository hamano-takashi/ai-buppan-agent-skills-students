# 返信と案内文の下書き

1. 相手、目的、伝える事実、期限、希望する口調を確認する。
2. 文体の見本は利用者が今回の目的で提供したものだけを使う。他人の私信や講師の文体データを読み込まない。
3. 事実と依頼事項を中心に書く。不明な金額や期限を補完しない。
4. CRM配信は ec-crm-review-panel、legal-check、platform-policy-check で確認する。私的な短い返信に不要な広告表現を追加しない。
5. 宛先と全文を提示する。送信は明示承認後のみ。送信前に宛先・添付・共有範囲を再確認する。

個人の文体設定・記憶を恒久保存する場合は利用者が希望したときだけ行う。

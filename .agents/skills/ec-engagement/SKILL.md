# 顧客との関係を整える

今回の顧客、購入状況、商品、連絡の目的、同意の範囲を確認する。初回配信なら過去実績は「なし」と記録し、商品事実と今回の目的から下書きを進める。

## 顧客対応

問い合わせの内容、確認済みの事実、対応可能な範囲、担当、期限を整理する。返品や補償を規約と権限の確認なしに約束しない。

## 配信設計

1. 対象者と届ける理由を明確にする。
2. 配信同意・解除・送信頻度・必要な情報を確認する。
3. 初回案内、利用支援、再購入など、顧客の段階に合わせる。
4. 文体は利用者が今回示した希望や使用を許可した見本に合わせる。専用ブランドファイルがなければ未確認の表現を区別する。
5. ec-crm-review-panel、legal-check、platform-policy-check の確認を行い、指摘は生成側で修正する。
6. 内容・宛先・時刻・リンクを提示して承認された範囲だけを送信する。下書き作成を配信許可と解釈しない。

効果は配信件数、クリック件数、問い合わせ件数、購入件数、解除件数など取得できる実数から検証する。実績がなければ基準を捏造せず、測定条件を先に決める。

詳しい手法は references/ 内のRFM、LTV、顧客支援の資料を必要に応じて参照する。個人の購買履歴を共有教材へ保存しない。

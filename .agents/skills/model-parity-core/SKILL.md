# 判断品質の確認

特定のAI会社・モデル・料金プランに依存しない。実際に利用できる機能を確認する。モデルの役割を宣言しただけで独立評価したことにしない。

1. 再定義: 目的、成功条件、制約、不足するデータ。
2. 分解: 結果を主要因へ分ける。相関だけで原因を断定せず、検証可能な仮説にする。
3. 比較: 判断を伴う施策は実行案・別案・現状維持を効果、費用、手間、リスクで比較する。単純な変換作業に形式的な比較を強制しない。
4. 検証: 下の六軸で点検し、足りない根拠や手順を直す。
5. 提出: 結論、根拠、次の実行、確認時点、残る不確実性を簡潔にまとめる。

六軸は、課題の具体性、資料の裏付け、代替案、実行可能性、リスクへの対応、伝わりやすさ。各軸1〜5で自己点検し4未満は修正する。採点は品質保証や第三者認証ではない。計算は別の方法でも検算する。

重要な対外成果物は可能なら生成者とは別のレビュー役が確認する。独立レビューがないときはその限界を明示し、公開・契約・費用は利用者が決める。

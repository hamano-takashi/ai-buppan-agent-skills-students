# 作業の検証

1. 依頼範囲と変更内容を照合する。
2. 実際の言語・構成・既存コマンドから必要なテストを選ぶ。存在しない npm スクリプトを必須にしない。
3. 個人情報、認証情報、外部送信、課金、本番変更、削除の扱いを確認する。
4. 失敗時は原因と修正を確認し、変更に関連する検証を再実行する。
5. 動作したこと、静的に確認したこと、未検証を分けて報告する。

スキルのルール文や .gitignore は強制保護の保証ではない。Git履歴や実際の送信先も確認する。

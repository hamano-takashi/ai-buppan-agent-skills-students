# Amazon商品名75文字＋商品のハイライト 設計・移行スキル

> 本スキルは単独で完結する。人格・広告運用・KW軍制の全体像が必要なときだけ
> `../ec-amazon-ops-veteran/SKILL.md`（Skill 16/21/22）へ。
> 規約値・表示仕様は変更される前提。確定前に platform-policy-check で一次ソース（セラーセントラル公式）を照合（Fail Closed）。
> 広告文・商品説明に数値・実績・No.1表現を使う場合は fact-check＋legal-check 必須（Rule 7）。

## 1. 制度の確定事項（2026-07-27施行）

| 項目 | 内容 |
|---|---|
| タイトル上限 | スペース込み75文字以下に統一（メディア除く全カテゴリ・グローバル） |
| ハイライト | 別枠最大125文字。タイトルと合わせ計200文字 |
| 検索 | ハイライトは検索対象（セラーセントラル公式アナウンス） |
| 超過時 | AIの推奨内容へ順次自動書き換え。個別通知は届かない |
| レビュー枠 | ブランド登録者のみAI更新前に14日間の確認・修正・承認。未登録は書き換え後に直すことになる |
| 入力場所 | セラーセントラル「在庫→全在庫の管理→出品情報の編集」 |
| 商品名要件（2025-01-21〜） | 禁止特殊文字あり・同じ単語は最大2回まで |

## 2. 表示形態の注意（設計の前提）

- 記事（7/20）は「商品名の下に二段表示」と説明。一方、社内実機確認（2026-06-14スクショ）ではタイトル直後に連結された1本の文字列として表示された。施行後に対象ASINの実機表示を必ず再確認する
- どちらの表示でも有効な設計原則: 200文字を頭から尻尾まで一続きに読んで意味が通ること・語の重複を作らないこと
- スマホでは後半が省略される。先頭ほど読まれる前提で並べる

## 3. 移行設計（何を残し、何を移すか）

### タイトルに残す4要素（優先度順）
1. ブランド名（指名検索の受け皿・先頭）
2. 商品を特定する語＝カテゴリ名
3. 検索頻度ランク5桁台までのKW（ブランド分析「上位の検索用語」で判定。3〜4桁=ビッグ、5桁=ミドル。ここまでタイトルに残す）
4. 識別に必要な仕様（容量・入数・サイズ・型番）

アパレル以外は75字上限でも、可能なら50文字前後まで簡潔に。

### ハイライトへ移す4情報
1. 素材・成分（綿100%・無添加・国産原料 等）
2. 容量・サイズ・入数の補足（500ml・Mサイズ・30袋入り 等）
3. 使用シーン・用途（ギフト用・業務用・車中泊向け 等）
4. 対応機種・適合条件（iPhone対応・8畳まで・食洗機対応 等）

## 4. ハイライトの書き方の型

- 半角カンマ（,）区切り。スペース・全角読点は避ける
- 5項目程度・1項目20文字前後
- 買い物客が比較で最初に気にする情報から並べる（先頭重要）
- タイトルとハイライトで同じ語を繰り返さない。タイトルに容量・本数・アテンション語を入れたら、ハイライトでは再掲せず別情報へ差し替える
- 役割分担: タイトル=検索を取る＋選ぶ理由の短句（CTR）／ハイライト=素材・仕様・用途の比較タグ
- 1軍KWをハイライトに賭けない（検索対象ではあるが、1軍はタイトル維持）
- 空欄のまま放置は機会損失
- 作成前に対象ASINの現行メイン画像を確認し、画像・タイトルと重複する情報を除外。画像に載っている主張でも、元データ未確認の実績（累計販売数・受賞・No.1等）はタイトル・ハイライトへ転用しない

### 実例
- ドリップコーヒー: タイトル「◯◯珈琲 ドリップコーヒー 深煎りブレンド 50袋入り 個包装 自家焙煎」＋ハイライト「1袋10gで濃さを調整しやすい粉量,常温保存で賞味期限は約12ヶ月,ギフト箱・のし対応,内祝い・お中元・お歳暮向け,酸味ひかえめのコク重視の味わい」
- 除湿剤: 「押入れ・下駄箱にも使えるスリム形状,1個あたり約450mlの吸湿量,効果の目安は約3〜4ヶ月,水位が見える窓付きで交換時期が分かる,フック付きで工具不要」
- モバイルバッテリー: 「iPhone・Android・タブレット対応,PD最大20W出力,スマホ約2回分の充電容量,重さ約180gで機内持ち込み可,残量4段階表示」

### NG
- プロモーション文言（送料無料・最安値・セール中）
- 主観・抽象表現（最高級・大人気・話題の）
- 記号・絵文字・装飾の多用（・【】等）
- 他社ブランド名・無関係KW
- 薬機法・景表法NG表現（タイトル同様に legal-check 適用）

## 5. 実施手順（1ASINあたり）

1. ブランド分析で検索頻度ランクを取得し、残すKW（5桁台まで）と移す情報を仕分け
2. 現行タイトル・順位・セッション・販売個数をスプレッドシートに控える（変更検知の基準）
3. タイトルとハイライトを同時に完成させ、200文字を一続きで読み直して重複・不自然を除去
4. legal-check（薬機法・景表法）→ ブランド登録者はレビュー枠で確認→一度で反映
5. 反映後、意図したKWが全て入っているか目視で突き合わせ

## 6. リスクと監視運用

- 最大リスク＝狙っていたKWが商品名から消えたことに気づかないまま流入が落ちること（AI自動書き換えは通知なし）
- 施行後は売上上位ASINの商品名を週1回目視確認。控えと突き合わせて変更を検知
- 順位変動の目安: 反映ラグ約1週間。ビッグワード1位→3位程度→約1ヶ月で回復が通常。大幅変更は月商7〜8割へ落ちる例あり。判断は単月でなく数週間の水準変化で
- 季節商材はピークのおおむね1週間前が実施目安。移行前後はFBA在庫を前倒し補充（直近ペース2ヶ月分常備）
- 工数配分: 売上上位2割に集中。売上小・指名検索中心・元々短いSKUはAI推奨を確認して通してよい

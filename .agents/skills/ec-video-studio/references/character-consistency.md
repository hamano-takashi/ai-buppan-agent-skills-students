# 人物と商品の一貫性

利用権限を確認した画像から、維持する特徴を整理する。他者のチュートリアルのプロンプト全文や無許可の人物写真を配布しない。

- 人物: 顔立ち、髪型、体格、服装、表情、姿勢。
- 商品: 外形、寸法比、素材、色、ロゴ、印字、部品の位置。
- 撮影: 光の方向、背景、視点、レンズ感、色調。

正面・横・背面・寄りなど必要な視点を利用者の許可された素材で確認する。見えていない部分は推測と明示し、実商品仕様として生成しない。
生成指示では編集対象、参考、保持する要素、変更する要素を分ける。実在商品は実物写真を基準にし、一枚ごとに見比べる。
画像生成は image-generation に従う。動画ではカットをまたぐ顔・形状・印字の変化も確認する。

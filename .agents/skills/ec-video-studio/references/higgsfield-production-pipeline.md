# Higgsfield 映像制作パイプライン（接続〜音楽PV/映像生成の実演手順）

Claude（チャット/Claude Code）にHiggsfieldを接続し、対話だけでプロ品質の
映像（音楽PV・CM・演出カット）を作る手順。
出典: 実演チュートリアル動画（2026-07、16.5分）の全文文字起こし＋フレーム単位解析
＋Higgsfield公式MCPガイド（https://higgsfield.ai/mcp 2026-07-05確認）。

## Higgsfieldとは（前提）

- Nano Banana Pro / Kling 3.0 / Seedance 2.0 / Veo 3.1 / GPT Image系（サービス側の現行対応を確認） / Soul 2.0 等、
  話題の生成AIを1契約・1箇所で使える統合プラットフォーム（画像・動画・音声・3Dで50種類以上）
- MCP接続の本質的価値: 各社モデルを個別にAPI契約すると企業向けの高額料金になるが、
  Higgsfield MCP経由ならいつものサブスクのクレジット範囲で全モデルをClaudeから直接動かせる

## 接続（初回のみ・実演確認済み）

- 必ずデスクトップアプリ版Claudeを使う。ブラウザ版はクラウド上で動くため
  ローカルファイル操作（素材の自動参照・保存・整理）ができない
- MCP方式（推奨・実演者実証）: 設定 → コネクタ → カスタムコネクタを追加 →
  名前「Higgsfield」＋URL `https://mcp.higgsfield.ai/mcp` → 追加 → Higgsfieldにログインで完了。
  一度繋げばClaudeチャットとClaude Codeの両方で使える
- CLI方式: コマンドで直接導入（公式はClaude Code/Codex等にはCLIも案内）。どちらでも可
- 認証: APIキー不要・Higgsfieldアカウントのサインインのみ
- 操作許可ポップアップ: 「一度だけ許可」or「常に許可」（常に許可=同種操作をセッション中スキップ。
  同じ作業を繰り返す時はスムーズ）

## Claude Code×MCPが「普通のAI動画生成」と違う点（実演の核心）

1. プロンプト設計→生成実行まで一気通貫: LLMにプロンプトを書かせてコピペする必要がない。
   「じゃあこれで生成して」でClaudeがそのままHiggsfieldで実行。
   「バリエーションを変えて4枚、並列で」も一言
2. ローカル素材と直結: 素材をいちいちアップロードしない。「この画像を参照に使って」で
   フォルダから自動取得。生成物のダウンロード・命名・フォルダ分け保存まで自動。
   注意: 参照渡しもHiggsfieldクラウドへの外部送信。SKILL.mdの外部送信ゲート
   （GWチェック＋毎回ユーザー事前承認）を適用してから渡す
3. 画像の中身を見て判断: ファイル名が適当でも、Claudeが画像を認識して
   「これはキャラ3面図」「これはヘッドホン」と判断・整理できる
4. 足りない機能はツール導入で自走: Claude本体に無い機能（例: ボーカル分離）は、
   オープンソースの優秀なツールを自分でインストールして解決する（後述Demucs）。
   質問に答えるだけでなく「解決するところまでやる」のがClaude Codeの違い
5. 音声入力が速い: Claude Code入力欄のマイクボタン、またはCtrl+D押下中のみ音声入力。
   誤字があってもClaudeが文脈で読み取るので気にせず喋ってよい（タイピングの体感100倍速）

## 音楽PV制作の実演手順（再現ステップ・実測）

実演は「乙姫様（AIシンガー）×浦島太郎（ギター）」のMV。全工程:

1. 下準備＝フォルダ整理を任せる: 作業フォルダにキャラクターの3面図
   （=キャラクターシート。character-consistency.md）・小物素材を置き、
   「整理して」で内容別にフォルダ分けさせる
2. ブランド小物の合成（`generate_image`）: ベース画像＋ロゴ画像から
   「ロゴ入りヘッドホン」を2パターン同時生成→プレビュー確認→
   「これを採用で」→保存まで自動
3. 小物の情景カット: 「マイクスタンドのブームにロゴ入りヘッドホンが掛かっている画像」を同じ要領で
4. 歌唱カット: キャラ3面図＋採用ヘッドホンを参照に
   「ロゴ入りヘッドホンを装着してマイク前に立つ、歌う直前のバストアップ」を2パターン→採用。
   実演の実プロンプト型（same identity構文）:
   ```
   Edit the scene from the reference image: keep the exact same woman
   (same face, identity, long straight black hair with blunt bangs),
   the same over-ear headphones with the [ロゴの詳細],
   and change only the background to a pure white studio (THE FIRST TAKE style).
   ```
   調整点（表情=歌う直前の緊張感/微笑み・衣装・高画質2k）はClaudeがパターン提案→ユーザー選択
5. 冒頭動画の生成: Seedance 2.0で15秒動画（3面図＋ヘッドホン＋マイクスタンド画像を渡す）。
   本来は複数本生成して良いところだけ編集で使うのがセオリー
6. 楽曲の用意: チュートリアルでは既存音源を使用（楽曲生成は範囲外）。
   自作する場合は商用利用条件を確認したAI音楽ツールか `generate_audio` を使う
7. ボーカル分離（リップシンク品質の鍵）: 楽器音が混ざると口の動きが引っ張られるため、
   ボーカルだけの音源でリップシンクを作る。分離は Demucs
   （オープンソース・無料・商用利用OK・有料サービス以上の精度）をClaude Codeに
   インストールさせ、「この音源をボーカルと伴奏に分離してフォルダに保存して」の一言で完了
8. リップシンク生成＝Kling Avatar: 歌唱バストアップ画像＋ボーカル音源でリップシンク動画。
   注意（2026-07時点）: リップシンクだけはMCPから直接動かせない。HiggsfieldのUIを手動操作
   （今後のMCP対応待ち）
9. コスパ設計（実演の工夫）: 歌唱シーンはカット1枚だけで全構成（本来は+2角度が理想）。
   リップシンクだけでは退屈なので、別キャラのギター演奏インサート（Seedance 2.0）を
   生成して編集で間に挟む。これだけで「それっぽく」仕上がる
10. 編集: 動画編集（ffmpeg / sns-video-editing.md）でリップシンク＋インサートを音源に合わせて構成
11. QC→提出: quality-gates.md の10軸＋Judge Gate

## 用途別モデルの使い分け（実演の結論）

| 用途 | 運用への適用（静止画は2026-09-09更新） |
|---|---|
| 静止画（人物・合成） | Codex組み込み画像生成（標準対象=Images 2.5）。Higgsfield上の2.5対応・モデル選択・サイズは利用時に確認 |
| 画像→動画（演技・演奏） | Seedance 2.0（720p/15秒級） |
| リップシンク | Kling Avatar（※MCP未対応・手動UI） |
| ボーカル分離 | Demucs（ローカル・無料・商用OK） |

「用途ごとに一番得意なモデルを、Higgsfield 1つの中で使い分ける」が統合プラットフォームの
最大の強み。迷ったら `models_explore(action:'recommend')` で推薦を受ける。

## 定型ワークフロー（説明動画・広告・UGC等）

ナレーション付き説明動画・CM・UGC風・ポッドキャスト等の「型がある動画」は、
自己流で組む前に必ず `get_workflow_instructions`（引数なし）でカタログを確認し、
該当ワークフローがあればその公式手順に従う（バンドル指定があれば `get_workflow_bundle_file`）。

## コスト規律（従量課金・実測値）

- プラン（2026-07時点・年払い30%オフ）: Starter 〜$9 / Plus $19 / Ultra $99（月3,000クレジット）。
  MCPで本格運用するならUltra級が目安
- クレジット感覚（Ultraの3,000で）: Seedance 2.0 720p 15秒動画≈月40本 /
  生成枚数は利用時のプラン・モデル・品質・サイズで再計算する。旧モデルの枚数例をImages 2.5へ転用しない
- 単体クレジット買い足し可。ただし買い足し分は90日で失効
- 生成前: `balance` で残高確認→想定消費をユーザーに提示して承認
- 最小テスト原則: スタイル確定まで1枚ずつ→確定後に量産。再生成は不合格カットのみ
- 高価な工程（動画化・アップスケール）は静止画段階の合格後にだけ実行

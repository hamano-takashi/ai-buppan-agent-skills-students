# 動画・画像制作 品質ゲート（VIDEO QC RUBRIC）

「高品質になるまで・事例以上になるまで」を判定者の裁量でなく機械的チェックで
担保するためのルーブリック。実行モデルが何であれ（Opus/Sonnet/Haiku/外部AI）、
このゲートを通過した成果物だけを提出する（Rule 10準拠）。

## ベンチマーク（合格の下限＝この実例以上）

| 種別 | 基準実例 | 合格の意味 |
|---|---|---|
| ショートドラマ | GENEL「卒業式」第1話（54秒/27カット/実写級/キャラ完全固定） | 全QC軸でこの実例と同等以上 |
| 音楽PV | Higgsfieldチュートリアル THE FIRST TAKE風PV | 構図・ブランド一貫・スタジオ実写感が同等以上 |
| SNS編集動画 | チャエン実証（ジャンプカット+テロップ+BGM+サムネ全自動） | 手動編集ソフトの標準品質と区別がつかない |
| 商品広告動画（Mode C） | MYTREX WEBCM群（539万回再生「ヒミツ」篇等）＋LP動画群（解剖= creative-trends/analyses/2026-07/mytrex_dtc-video-ads.md） | 下記「広告クラフト7基準」を全て満たす。既存素材の紙芝居（静止画パン連結のみ）は広告としては不合格 |

## 広告クラフト7基準（Mode C広告はQC10軸に加えて全て必須・2026-07-06新設）

プレミアムD2C広告（MYTREXアンカー）の実測から規範化。1つでも欠けたらREVISE。

| # | 基準 | 検証方法 |
|---|---|---|
| 1 | フック0-3秒=コピー1本・数字・意外性のいずれか。商品ロゴ/パッケージから入らない | 冒頭3秒のフレームで判定 |
| 2 | 情報密度: 平均カット長2.5秒以下（20秒≥8カット/30秒≥12カット）。3秒超は感情ピーク1箇所まで | カット表実測 |
| 3 | オンスクリーン数値・図解を2箇所以上（分量・杯数・時間・%を矢印/グラフ/単位付き大型タイポで絵にする。数値はfact-check通過分のみ） | キーフレームで指差し確認 |
| 4 | 機能可視化カット1つ以上: 実写マクロ or 内部CG（食品=溶解マクロ・注ぎスロー・湯気等のシズル物理） | カット表で該当カット特定 |
| 5 | 製品ヒーローショット（クリーン背景×ライティング・実物写真ベース）を1回以上。締めは製品/ブランドで終える | 最終カット確認 |
| 6 | タイポ2層: メインコピー=キネティック（出現アニメ付き大型） / 法務・出典・イメージ注記=脚注常設 | テロップ書き出し |
| 7 | モーションローテーション: 同種モーション（ズーム/パン等）は2連続まで。タイポ・マクロ・図解・人物でリズムを作る | カット表のモーション列 |

## 動画QC 10軸（各5点満点・全軸4以上で合格）

| 軸 | 5点の状態 | 検証方法 |
|---|---|---|
| 1. キャラ/被写体一貫性 | 微細特徴（肌・髪・衣装・ロゴ）が全カット同一 | 顔アップを並べて拡大比較 |
| 2. 実写度/AI感排除 | 実写と見分けがつかない（実写度8.5+、下記採点アンカーで機械採点）。装飾エフェクトなし | AI感チェックリスト5項目をクロップ静止画で判定 |
| 3. 物理整合 | 手指・目・文字・液体の流れ・左右が全カット正常 | 全カットの拡大静止画チェック |
| 4. ショット文法 | 引き/寄り/パーツ/角度がローテーションし、同画角2連続なし | カット表で画角を列挙 |
| 5. テンポ | 1カット1.5〜3秒。3秒以上の停滞なし | タイムライン実測 |
| 6. 字幕/テロップ | 誤字ゼロ・1カット1文20字以内・セーフエリア内・可読 | 全字幕を書き出して校正 |
| 7. 音 | 声/BGM/SEのバランス、音切れなし、ラウドネス正規化済み | カット点±0.3秒聴取・loudnorm確認 |
| 8. 構造 | フック0-3秒・感情の積み上げ・転・引き(CTA)が設計通り | 構造テンプレと突合 |
| 9. ブランド/目的適合 | トンマナ・ロゴ・NG表現がブランドガイド準拠、目的KPIに接続 | ブランドガイド・依頼要件と突合 |
| 10. 仕様適合 | アスペクト比・解像度・尺・ファイル形式が配信先仕様どおり | platform-policy-check（確認日付き） |

## 実写度の採点アンカー（AI感チェックリスト・採点者非依存）

クロップ静止画（顔・手・小物・文字・光源の5箇所以上）で以下5項目を判定し、機械的に減点する:

| # | AI感の兆候 | 軽微（-0.5） | 明確（-1.0） |
|---|---|---|---|
| 1 | 過剰な肌ツヤ・プラスチック感 | 一部カットのみ | 主要カットで明白 |
| 2 | 装飾エフェクト（光輪・粒子・浮遊） | 背景に薄く | 被写体周囲に明白 |
| 3 | 整いすぎ（完全左右対称・毛穴ゼロ・歯が均一） | 1要素 | 2要素以上 |
| 4 | 破綻（手指・目・歯・文字・アクセサリ） | 拡大でのみ視認 | 通常再生で視認 |
| 5 | 光と影の物理不整合（影の向き・映り込み） | 1箇所 | 2箇所以上 |

- 採点 = 10.0 − 減点合計。8.5未満は不採用（該当カットのみ再生成）
- オーバーライドルール（減点計算より優先）: 「明確」が1項目でもあれば採点値に関わらず不採用
  （通常再生で気づくAI感は即不採用。減点表は「軽微」の累積判定用）
- イラスト調・アニメ調の案件では本アンカーは「絵柄の一貫性」チェックに読み替える

## 必須ゲート（点数に関係なく未通過ならREVISE）

- 広告・商品説明・実績数値を含む → fact-check
- 体験談風・効果訴求・比較表現 → legal-check（ステマ規制・景表法・薬機法）
- プラットフォーム掲載（Amazon/Instagram/TikTok等） → platform-policy-check（参照URL＋確認日）
- 外部送信（生成のための素材アップロード・クライアント納品・SNS投稿） →
  外部送信ゲート: `利用可能な機密チェック（未導入なら送信内容を手動確認）`で機密・個人情報・案件固有情報を検査。
  `block`/`review`=送信しない。GW/Ollama停止時はFail Closed。`allow`でも毎回ユーザー事前承認

## 反復ループ（完成までの回し方・クレジット節約込み）

1. 最小テスト: 新しい画づくりはまず1枚（1カット）だけ生成し、軸1〜3を判定
2. 合格したらスタイルを固定（参照画像・プロンプト・モデル・設定を記録）して量産
3. 量産後にQC 10軸を通し、不合格カットだけ再生成（合格カットは触らない）
4. 3回再生成しても不合格の場合: 構図・モデル・素材を変える判断をユーザーに提案
   （同じ手を4回繰り返さない。実現可能性を正直に報告する）
5. 全軸合格 → Judge Gate（下記）→ 提出

## Judge Gate（Rule 10）

- 生成者と判定者はコンテキスト分離。メインセッションが生成した場合は
  利用可能な独立レビュー役（使えなければ役割切替の点検と限界を明示）に本ファイル＋model-parity-core の六軸を同梱して判定させる
- 判定者は QC 10軸を機械的に適用し、判定出力形式（model-parity-core準拠）で PASS/REVISE
- 最大3ループ。REVISE原因は 利用者の local/ に置く記録 に記録
- 動画そのものを判定者が再生できない場合: キーフレーム抽出画像＋カット表＋字幕全文＋
  音声波形/ラウドネス値を判定材料として渡す（本スキルの標準検証成果物）

## 検証成果物（提出時に必ず添付）

- カット表（カットNo/秒数/画角/字幕/音/使用モデル/生成プロンプト）
- QC 10軸の自己採点表（各軸の検証方法と結果）
- キーフレーム一覧画像（全カット）
- 必須ゲートの通過記録（該当時）
- 商品広告（Mode C）の場合: 商品マスター写真＋ラベル突合クロップ画像
  （Judge Gateが商品忠実性チェック#1を独立再検証できるようにする）

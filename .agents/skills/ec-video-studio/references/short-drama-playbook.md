# 短い物語で利用場面を伝える

既存作品の台詞、映像、キャラクターを複製せず、自分の商品で実際に起こりうる場面から構成する。

1. 視聴者が認識できる状況を示す。
2. 小さな困りごとや選択を一つ置く。
3. 商品の機能に裏付けられる行動の変化を見せる。
4. 結果と次の行動を明確にする。

架空例: 在宅勤務の休憩で道具を探す人物が、置き場所を整え、片付いた机へ戻る。映像で表せる範囲に絞り、実証のない集中力向上などを商品の効果にしない。

絵コンテにはカット、画、動き、台詞の有無、音、必要素材を記載する。実制作の前に物語と素材の権利を確認し、外部生成の費用と送信内容について承認を得る。

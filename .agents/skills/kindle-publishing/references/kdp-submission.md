# 出版前の確認と提出

利用者が自分のアカウントで確認した、最新のKDP公式手順と審査条件を使う。自動アップロード用スクリプトはこの教材に含めない。

1. 原稿、目次、表紙、権利、書誌情報、価格、対象地域を確認する。
2. 利用可能な編集・変換ツールでファイルを作り、プレビューで改ページ、文字、画像を確認する。
3. 書籍情報、AI利用に関する申告、販売範囲など現時点の必須項目を公式画面で確認する。
4. 利用者へ提出内容、権利設定、価格、公開範囲を見せる。
5. 明示承認後に利用可能な正規の手段で提出する。操作できなければ納品ファイルと手順を渡す。
6. 提出状態を確認する。審査・公開が完了していないのに出版済みと報告しない。

公式入口: https://kdp.amazon.co.jp/ 。規約や独占条件は platform-policy-check で利用時に再確認する。

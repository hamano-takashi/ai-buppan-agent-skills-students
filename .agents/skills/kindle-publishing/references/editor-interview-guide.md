# 著者への確認と原稿化

利用者が使用を許可したノート、スキル、過去資料から、既に分かることと本人への確認が必要なことを分ける。他人の私信や非公開の講座原本は転用しない。

1. 読者、読後にできること、著者が責任を持てる範囲を確認する。
2. 章ごとに経験、判断、根拠、反例、具体的な手順を聞く。
3. 不足資料と本人の負担に応じて時間を見積もり、複数回に分ける。
4. 数値や実績は本人談だけで確定せず、利用を許可された一次資料で確認する。
5. 確認できない数値は掲載しない。丸めたり体感と言い換えたりして裏付けの代わりにしない。
6. 意見や経験の解釈は本人の見解として分け、原稿化した後に本人へ確認する。
7. 記録の保存先と内容を示し、外部へ保存する場合は利用者の承認を得る。

執筆には著者の言葉と、読者が使える説明を両立させる。事例で第三者を特定できる場合は同意・匿名化・掲載範囲を確認する。

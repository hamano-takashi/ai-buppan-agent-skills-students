# 規約・仕様の確認

スキル内に書かれた過去の仕様や経験則を、そのまま現在の公式規定として扱わない。

1. 国・媒体・対象機能・作業日・確認したい行為を特定する。
2. 公式ヘルプ、管理画面の告知、利用者が権限を持つ公式資料を読む。公開Webの閲覧には非公開の商品名や顧客名を検索語として送らない。
3. 規定本文、対象範囲、施行日、例外を確認する。閲覧できない情報は未確認とする。
4. 「公式で確認」「利用者の管理画面で確認」「経験則」「未確認」を分け、参照URLと確認日を残す。
5. 施策と規定を照合し、必要な修正を示す。規約に反するデータ取得や操作は進めない。

個別アカウントへのログインや非公開講座の抽出を勝手に行わない。ツールの利用可能性と、その対象サービスが操作を許可しているかを別々に確認する。

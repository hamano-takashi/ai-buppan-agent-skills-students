# 議事録とタスク案

利用者が共有権限と利用目的を確認したメモ・文字起こしを使う。

1. 決定事項、未決事項、担当、期限、次回確認事項を抽出する。明示されていない担当・期限は未定とする。
2. 議事録本文とタスク一覧をローカルで作成する。全文の文字起こしや個人情報は必要最小限にする。
3. Notionが接続されていなければMarkdownで納品する。アカウントや有料契約を勝手に追加しない。
4. 保存を依頼されたら対象プロジェクト・保存先・本文・機密区分を確認する。候補が複数なら利用者に選んでもらう。
5. 承認範囲が確認できてから保存先を再取得し、スキーマ、共有範囲、重複を確認して追記する。
6. 保存URLと作成内容を報告する。全文文字起こしのアップロードは別途必要性と承認を確認する。

ログの保存手順は worklog に従う。

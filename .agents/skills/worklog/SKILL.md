# 自分の作業ログ

利用者が指定したプロジェクト内のログだけを調べる。ログ一覧がなければ、local/ 内の利用者自身のファイルをファイル名・更新日時・キーワードで探す。他の受講生や講師の記録にはアクセスしない。

記録項目は日時、依頼、決定、成果物のパス、検証済み、未検証、次アクション、機密区分。本文にパスワードやAPIキーを残さない。

ローカル記録は local/ に保存する。Notion等へ保存する場合は、要約・送信内容・保存先を示して利用者の承認を得る。書き込み直前に保存先を再確認し、既存ログとの重複を確認して追記する。自動送信を設定しない。

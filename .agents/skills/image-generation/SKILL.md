# 画像生成・画像編集

すべての画像生成・画像編集の依頼で、利用可能なCodexの組み込み画像生成を標準にする。利用環境の公式 imagegen スキルがあればその手順に従う。ユーザーが別方式を明示した場合は指定を優先する。

1. 用途、被写体、必要な形、参考素材、文字、保持する要素を確認する。
2. ローカルの編集対象画像を先に閲覧する。実在商品は利用者が権利を持つ実物写真を基に編集し、形状・表示・ロゴを確認する。
3. 組み込み画像生成ツールで実際に生成する。APIキーを追加するよう求めず、プロンプトだけで完了にしない。
4. 画像を閲覧し、依頼との一致、文字、商品同一性、手や物体の整合、不要なロゴを確認する。
5. 保存先が指定されたら結果の実パスからコピーし、存在を確認する。依頼なく既存画像を上書きしない。

組み込み機能がない・失敗した場合は明示する。従量課金API、CLI、別モデルへの切り替えは利用者の選択後だけ行う。内部モデルIDを指定・確認できなければ Images 2.5やFlare/Sunburstに固定したと断定しない。
広告や商品画像は ec-creative、ec-amazon-image-generator、fact-check、legal-check、platform-policy-check の該当手順を併用する。外部送信・素材の権限は AGENTS.md に従う。

標準対象はChatGPT Images 2.5。「imege2.5」も同じ画像生成意図として扱う。変更箇所・保持要素を具体化し、複数回編集でも実物と比較する。透過はアルファを保持したPNG/WebPで確認する。API版と組み込み機能の違いは [移行ガイド](../../../docs/IMAGES_2_5.md) を参照。

# Free Source Map

Use this reference when selecting a free or low-cost source.

| Need | Preferred source | Free constraint | Notes |
|---|---|---|---|
| YouTube channel/video stats | YouTube Data API | Default quota; search is expensive | Prefer known channel/video IDs. |
| Public page verification | Codex Chrome plugin/direct Chrome access | User must have it available | Good for screenshots and manual-style checks. |
| YouTube transcripts | Public transcript tools or page extraction | Availability varies | Respect rights and quote limits. |
| Threads public posts | Official access or public web | Availability varies | Public data only; no scraping by default. |
| X/Twitter public posts | Official access or public web | Availability and metrics vary | Verify important claims manually. |
| Instagram public profile/post sampling | Official access or public web | Small manual sample only | Avoid login-gated/private data. |
| TikTok public trend sampling | Official access or public web | Small manual sample only | Metrics can change quickly. |
| Owned account analytics | User export CSV/XLSX | User must provide export or auth | Prefer exports for accuracy. |

If a source is unavailable, state the fallback and reduce confidence. Third-party scraping/extraction services require an explicit user request, current policy verification, bounded scope, and approval for cost/external transmission.

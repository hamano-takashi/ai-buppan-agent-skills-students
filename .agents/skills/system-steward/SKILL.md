# スキルとルールの保守

読み取り点検から始め、削除・移動・外部保存は自動で行わない。

- SKILLS_INDEX.md と実ファイルの対応、frontmatter、参照先を確認する。
- 個人のパス、接続ID、認証情報、他の案件情報が共有対象にないか調べる。
- 古い価格、モデル名、規約、推奨設定は一次情報を確認し、確認日を記録する。
- 不要な重複や矛盾があれば、小さな差分を作り影響を説明する。
- 配布を更新するときは tools/validate_distribution.py と tools/test_validate_distribution.py を実行する。Pythonが使えない場合は手動点検と限界を記録する。
- 実行していないテストや存在しない自動保護を「有効」と報告しない。

結果は、問題箇所、影響、修正案、確認方法で示す。新しいルールや自動処理を増やすこと自体を成果にしない。

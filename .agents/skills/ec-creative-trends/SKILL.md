# 参考クリエイティブを調べる

利用者の参考画像、権利を確認した素材、閲覧できる公開情報を使う。私有のダイジェストや収集プログラムがある前提にしない。

1. 対象顧客、商品、媒体、探す表現を絞る。
2. 参考の公開元と確認日を記録する。掲載順位や表示回数を売上の証拠としない。
3. 構図、情報の順番、色、余白、文字量、写真の役割を分解する。
4. 借りるのは原則や構造。画像・ロゴ・コピーを無断転載しない。
5. 自分の商品へ適用する案と、合わない点を示す。制作は ec-creative と image-generation に渡す。

参考画像を外部生成サービスへ入力する場合は、その利用権限と送信範囲を確認する。

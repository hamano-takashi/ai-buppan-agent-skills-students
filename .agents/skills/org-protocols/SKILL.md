# 共通の作業手順

リポジトリルートの AGENTS.md を共通ルールの正本とする。このスキルと矛盾する古い参考記述があれば AGENTS.md を優先する。

1. 目的、完成物、対象商品、利用資料、作業範囲を確認する。
2. 対象商品の一次資料を読む。不足があれば未確認として残し、独立して進められる作業を進める。
3. SKILLS_INDEX.md から必要なスキルを選ぶ。
4. 下書きと必要な検証を完了し、外部反映があるときは具体的な内容・宛先・費用・影響を示す。
5. 利用者の明示承認の範囲で実行する。承認済みの同じ行為を繰り返し確認しない。宛先・内容・費用が変わる場合は再確認する。
6. 実行後に現物を確認し、変更点、検証済み、未検証、次の一歩を報告する。

公開情報の閲覧は進められるが、非公開情報を検索語に含めない。自動配信・定期処理・自動課金はこの教材に含めない。

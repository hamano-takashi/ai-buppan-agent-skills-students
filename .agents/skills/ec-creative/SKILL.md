# 商品の価値を伝える制作

今回の目的、顧客、商品仕様、掲載先、利用可能な素材を確認する。過去の資料やブランドルールがなければ、利用者が今回指定した条件を使い、不足事項だけを確認する。

1. 裏付けのある商品の価値と、最初に伝えることを一つ決める。
2. [制作チェック手順](references/masterprompt-protocol.md)に沿って、参考・構図・光・色・文字・固定要素を整理する。
3. 画像生成・編集の依頼は image-generation を使い、組み込み機能で実際に生成する。参考資料の不足を、私有のダイジェスト探索で補わない。
4. 商品ページの各画像は、主役、使用場面、特長、仕様、比較、安心材料など役割を分ける。
5. 実物写真にない効能・構造・付属品を捏造しない。表示する数字や商品属性はSKUごとに確認する。
6. 出力を閲覧し、文字、商品同一性、視線の流れ、光と物理的な整合を確認する。
7. 掲載前に fact-check、legal-check、platform-policy-check の該当確認を行う。保存・公開の承認範囲を守る。

文章や広告の設計では ec-emotional-marketing と ec-drm の考え方を必要な範囲で使う。心理理論を成果保証や未検証の数値にしない。

参照資料は制作の課題に応じて使い、全資料の読み込みを強制しない。

# 広告クリエイティブ構図・視線誘導 原則

制定: 2026-07-08

目的: 広告画像、Amazon商品画像、LPカット、Canva制作、画像生成、写真合成を作る際に、構図を「なんとなく」で決めないための基本原則。制作前に必ずどの構図・視線誘導を採用するか宣言し、完成後にその構図が画面上で機能しているか確認する。

## 最重要ルール

- 参照シートがある商品・人物は、構図以前に参照シートが正本。商品形状、厚み、立体感、素材、チャック、底マチ、ロゴ、印字、帯色、タブ位置、人物の顔立ち、髪型、体型、表情の癖を崩してはいけない。
- 参照シートは「切り抜いて貼る素材集」ではなく、AI画像生成で同じ人物・同じ商品に見えるように固定するための視覚資料である。ユーザーが明示しない限り、単純な切り抜き配置で代用しない。
- プロダクトシートの使い方はキャラクターシート法の商品版とする。正面、側面、背面、斜め、上、底、チャック、タブ、素材、開封、中身、スクープを1つの同一商品として学習・参照させ、生成後に同一性を検査する。
- 商品を「平たい板」「薄い紙袋」「ロゴだけ貼った箱」にしてはいけない。パウチ、ボトル、箱、布、金属などは、厚み・側面・底・折り・影・接地面で立体を証明する。
- 1枚ごとに主構図を1つ、補助視線誘導を1つまで選ぶ。複数法則を同時に詰め込み、視線が散る画面にしない。
- 構図は装飾ではなく、最初に見せるもの、次に読ませるもの、最後に行動させるものの順序設計である。

## 構図9選

### 1. 三分割構図
画面を縦横に3分割し、被写体をラインや交点上に配置する。自然なバランスを作りやすく、商品写真、広告バナー、Amazonサブ画像の基本にする。

使いどころ:
- 商品とコピーを同時に見せたい
- 上品・安定・自然な印象にしたい
- 初回案で迷ったときの基本形

注意:
- ただ左右に分けるだけでは弱い。交点に商品ロゴ、人物の目、主要コピー、バッジなどの視線フックを置く。

### 2. 放射線構図
線や背景要素を放射状に配置し、視線を被写体に集中させる。動き、迫力、キャンペーン感、商品への集中を作る。

使いどころ:
- 商品やロゴを強く目立たせたい
- セール、ローンチ、強い訴求
- 中央の被写体に一気に視線を集めたい

注意:
- 高級感・静謐感とは衝突しやすい。食品・美容・上質系では線を露骨に描かず、光、影、テーブル目、背景パースで作る。

### 3. 対角線構図
対角線に沿って要素を配置し、奥行きと動きを出す。視線が自然に流れるため、使用シーンや注ぐ/混ぜる/持つ動作に向く。

使いどころ:
- 注ぐ、振る、持つ、歩くなど動作がある
- 商品と人物を自然に接続したい
- 画面をアクティブにしたい

注意:
- 商品が歪んだり薄く見えないよう、商品自体は立体が分かる角度と影を残す。

### 4. 三角構図
被写体を三角形に配置し、安定感と動きを両立する。複数要素の関係性を見せる時に使う。

使いどころ:
- 商品、コピー、証拠要素の3点をまとめたい
- 人物、商品、使用物を1画面に置く
- 成分3ポイントや比較に秩序を出す

注意:
- 逆三角は緊張感、正三角は安定感が出る。用途に応じて選ぶ。

### 5. 日の丸構図
被写体を中央に配置する。単純で強く、商品やブランドメッセージを直球で強調できる。

使いどころ:
- Amazonメイン画像、単品商品写真
- ブランドの正面性を見せたい
- 商品を「主役」として疑いなく見せたい

注意:
- 退屈になりやすい。影、余白、質感、ロゴの読みやすさ、補助コピーの間隔で品質差が出る。

### 6. シンメトリー構図
左右対称・上下対称で整える。信頼、品質管理、比較、整然としたブランド感を作る。

使いどころ:
- 国内製造、品質、成分、ラインナップ
- 4味展開など整列した商品群
- 高級感や清潔感を出したい

注意:
- 完全対称は硬くなる。小さな光差、影、商品角度差で自然さを残す。

### 7. フレーミング構図
窓、アーチ、カード、布、テーブル、余白などで被写体を囲む。奥行きと集中を作る。

使いどころ:
- 使用シーンで商品を自然に目立たせる
- 文字情報をカード化して読みやすくする
- 世界観写真の中で商品を埋もれさせたくない

注意:
- フレームが主役を食わないこと。囲いは視線誘導であり装飾ではない。

### 8. クローズアップ構図
被写体に大胆に近づき、細部を強調する。質感、チャック、粉、シズル、結露、素材感に向く。

使いどころ:
- 商品の質感、粉の粒度、チャック、タブ、グラス結露
- 「おいしそう」「上質」「本物感」を出したい
- サブ画像で特徴を強調したい

注意:
- 何を見せたいクローズアップかを明確にする。寄った結果、商品が何か分からなくなるのは失敗。

### 9. C字構図
丸い皿、グラス、パウチの曲線、テーブル小物を画角から少し切り、画面外への広がりを作る。料理・飲料・商品シズルに強い。

使いどころ:
- カフェオレ、グラス、粉、スプーンなど丸みのある要素
- 余白にコピーを置きつつ写真に続き感を出したい
- 商品を大きく見せたい

注意:
- 切り方が中途半端だとただのトリミングミスになる。C字の内側に主役やコピーを誘導する。

## 視線誘導6法則

### 1. Z型
視線が左上から右上、左下、右下へ動く。バナー、ポスター、プレゼン、Amazonサブ画像の汎用基本型。右下にCTAや結論を置きやすい。

適用:
- 左上: メインコピー
- 右上: 商品・ロゴ・補足タグ
- 左下: 証拠・詳細
- 右下: CTA/結論/購入理由

### 2. F型
左上から右へ、その後縦方向へ読む。情報量が多いLP、商品紹介、成分表、手順説明に向く。

適用:
- 見出しを左に揃える
- 各行の先頭に数字・アイコン・チェックを置く
- 読まれない右側には重要情報を孤立させない

### 3. N型
縦書きや和文の印象設計に向く。情報量を絞り、ブランド世界観や強いキャッチを残したい時に使う。

適用:
- 文字量を少なくする
- 余白と大きなビジュアルを使う
- 世界観・印象を残す広告バナー向け

### 4. グーテンベルク・ダイヤグラム
左上のプライマリー視線エリアから右下のターミナル視線エリアへ流れる。左上に主メッセージ、右下に結論/CTAを置く。

適用:
- 左上: 最初に読ませるコピー
- 右上: ロゴや補助情報
- 左下: 補足・注記
- 右下: アクション/結論

### 5. 矢印効果
矢印、人物の視線、指差し、注ぐ流れ、テーブルラインなどで視線を誘導する。

適用:
- 露骨な矢印が安っぽい場合は、人物の視線、手元、注ぎ口、光、影で代替する
- CTAや主コピーの近くに自然な誘導線を置く

### 6. ホワイトスペース
余白で視線を集める。情報が多い画面ほど、重要情報の周囲に余白を確保する。

適用:
- 高級感、清潔感、信頼感を出す
- 商品やコピーの周囲を空け、埋もれさせない
- Amazon画像ではスマホ縮小時の可読性を保つ

## Amazon/EC商品画像への使い分け

| 画像タイプ | 推奨構図 | 補助法則 | 注意 |
|---|---|---|---|
| メイン画像 | 日の丸 / 三分割 | ホワイトスペース | 規約上、後付け文字入りは正式メインに不向き。商品は立体・高解像度。 |
| 成分・信頼 | F型 / 三角 | チェック・数字の視線フック | 数値は根拠確認。表は生成文字に任せず組版。 |
| フレーバー世界観 | 三分割 / C字 / クローズアップ | 対角線・ホワイトスペース | 写真のシズルを主役にし、文字は静かに置く。 |
| 3ポイント | F型 / 三角 | 数字の階層化 | 3段の情報密度を均一化しない。主ポイントを作る。 |
| パッケージ利便性 | クローズアップ / フレーミング | 矢印効果 | チャック、底マチ、厚みなど実物特徴を見せる。 |
| 飲み方・成分表 | F型 | ホワイトスペース | 表・数字・注記は必ず組版。 |
| 国内製造・安心 | シンメトリー | グーテンベルク | 認証マークや根拠不明のNo.1を入れない。 |
| 使用シーン | 対角線 / 三分割 | 人物の視線・手元誘導 | 人物同一性、手元、商品立体感を崩さない。 |

## 完成前チェック

1. 主構図を1つ宣言しているか
2. 補助視線誘導を1つまでに絞っているか
3. 最初に見る要素、次に読む要素、最後に残す要素が明確か
4. 商品が薄く、軽く、偽物に見えていないか
5. 参照シートのロゴ・印字・色・形状・厚み・素材が保たれているか
6. 人物シートがある場合、顔立ち・髪型・体型・表情が別人になっていないか
7. スマホ縮小時に主コピーと主商品が読める/分かるか
8. 構図法則を口で説明できるだけでなく、画面上の配置で実装できているか

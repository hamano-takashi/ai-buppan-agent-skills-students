# 参考画像から制作指示を組み立てる

利用者が共有権限を確認した参考画像と、自分の商品の資料を使う。以下は配布版の制作チェック手順であり、他者のマスタープロンプト全文・参考写真を同梱するものではない。

## 最初に決めること

一枚で完結する画像か、商品ページやLPの一部かを決める。実在商品の外観は実物写真を基準とし、生成による形状・印字・素材の変化を防ぐ。写真、文字、数字、ロゴの役割を分ける。

## 入力を具体化する

- 主題と掲載先。
- 顧客の場面、困りごと、求める変化。
- 商品で裏付けられる便益。
- 表現の温度、色、避ける印象。
- 最初に見せる要素、次に読む要素、最後にしてほしい行動。
- 人物の有無、光、背景、素材感、季節。
- コピーと数値の原本、使用可能なロゴ。
- 固定する形状・文字・比率・同一人物の特徴。

未提供の資料は未提供とする。他人の私的な資料がある前提で探索しない。商品写真が不足する場合は、背景等の独立した素材を先に作り、実商品が再現できたとは言わない。

## 参考を視覚要素へ分解する

| 要素 | 確認すること |
|---|---|
| 構図 | 主役の位置、大きさ、切り取り、視線の流れ |
| 光 | 向き、硬さ、影、反射、色温度 |
| 色 | 主色、背景色、差し色、コントラスト |
| 質感 | 紙、布、金属、液体などの見え方 |
| 背景 | 奥行き、余白、情報量 |
| 文字 | 級数、行間、量、写真との関係 |
| 補助要素 | バッジや図形が伝える意味と必要性 |
| 同一性 | 商品・人物・ロゴの固定条件 |

構図の詳細は [構図の確認](composition-principles.md) を参照する。参考のコピーや画像を転載せず、構造上の学びを自分の商品に合わせて組み直す。

## 制作指示を作る

SHOT: カメラ位置・画角・比率。
SUBJECT: 主役と実物写真の参照先。
SCENE: 背景・利用場面・小物。
LIGHT: 光源と影。
STYLE: 求める見え方。
COMPOSITION: 配置と文字用の余白。
PALETTE: 配色。
CONSTRAINTS: 固定する要素、変えない表示、追加しない要素。

素材の画像生成・編集は image-generation の手順で組み込み機能を使う。長い文章、正確な成分数値、比較表は必要に応じて生成後に組版し、見た目を再確認する。日本語が必ず正しく出るという保証はしない。

## 出力の確認

1. 依頼の目的・掲載先・比率に合っているか。
2. 実物の商品形状・ロゴ・印字が保持されているか。
3. 文字・数字は原本と一致するか。
4. 人物の手、持ち方、反射、接触、重力に不整合がないか。
5. 視線の流れと主役が明確か。
6. 色・光・質感が複数枚でそろっているか。
7. 余計な商品、ラベル、ロゴがないか。
8. 参考との比較で意図した構造が再現できているか。
9. 表現の裏付け、素材の権利、媒体規定を確認したか。
10. 保存した実ファイルを閲覧し、次工程で使えるか。

複数枚も一枚ずつ同じ確認を行う。修正点は具体的に絞る。全項目を確認していないのに検証済みとしない。

# オーナー社長の手取り最適化（日本・中小法人）— 役員報酬×旅費規程×資産防衛

> 対象: 日本の中小法人／オーナー経営者（役員1〜数名）。CFO Agent の Tax Strategy の実務層。
> 本ファイルは判断の枠組みであり、金額の確定値ではない。金額は必ず顧問税理士の承認で確定する。
> 個社の実額・自社の財務数値はここに書かない。

---

## 1. なぜ旅費規程なのか（制度の本質）

出張旅費規程に基づく日当・宿泊料は、給与ではなく旅費交通費として扱われる。結果として:

- 所得税・住民税がかからない
- 社会保険料の算定基礎に入らない
- 定額支給でよく、実費との差額が出ても課税されない
- 国内出張なら消費税の課税仕入れ。出張旅費等特例により帳簿のみの保存で仕入税額控除（領収書不要）

役員報酬で同じ現金を取ると、所得税・住民税・社会保険料の三重で削られる。
同じ現金を手元に残すなら旅費規程を通したほうが効率がよい — これが制度の本質であり、
「経費を増やして利益を消す」話ではない。

根拠: 所得税基本通達9-3／国税庁 No.6459／国税庁「出張旅費、宿泊費、日当等に係る仕入税額控除の適用要件」

---

## 2. 非課税の3要件（所得税基本通達9-3）

全部を満たしてはじめて非課税。 ひとつでも外れると超過部分が否認される。

1. その旅行に 通常必要 とされる費用の範囲内であること
2. 役員・使用人の全部を通じて適正なバランス が保たれた支給基準であること
3. 同業・同規模の他社と比較して相当 と認められる金額であること

→ 規程の適用範囲は「全役職員」にする（②への対応）。役員限定の規程にしない。
→ 比較対象は 同業同規模の民間企業（③）。ここが金額設定の唯一の物差し。

---

## 3. 設計の型

| 費目 | 支給方式 | 備考 |
|---|---|---|
| 交通費 | 実費精算 | 標準形。定額支給と混ぜない |
| 宿泊料 | 役職別・地域別の定額 | 差額が出ても相当額なら課税されない |
| 日当（出張手当） | 役職別の定額 | 半日／全日の区分を設けるとよい |

区分は 役員／部長・課長／一般 の3層＋地域別（都市部と地方）。
一律にすると要件②③の説明が弱くなる。

必須の運用物:
- 出張旅費規程（株主総会または取締役会の承認・議事録を残す）
- 出張報告書（日付・行先・目的・訪問先）— 領収書が不要なぶん、出張の実態を示す唯一の証拠
- 旅費精算表（区間・交通費・宿泊日数・日当）

## 4. 否認ライン（ここを踏まない）

### 4-1. 最も否認されやすい構図

「役員報酬が低いのに日当が高い」。 複数の税理士事務所が、
所得税を逃れるための規程とみなされて指摘を受けやすい典型として名指ししている。

否認されたときの損失は二重: 役員賞与認定 → 損金不算入（法人税）＋源泉所得税の追徴。
仮装隠蔽と認定されれば重加算税。制度の利得より損失のほうが大きくなる。

裁判例: 代表者に日当3,000円・役員配偶者に2,000円を支給していた事案で1,000円超が否認された
（宇都宮地裁 昭和50年10月16日判決とされる。正確な引用は税理士に確認）。判決は
「『日当』という名による合法的脱税がいくらでもまかりとおることになる」と述べている。
→ 金額の絶対水準が低くても、事業規模との均衡を欠けば否認される。

### 4-2. 「国家公務員・国会議員基準に合わせれば安全」は成り立たない

2つの理由で使えない。

1. 要件③の比較対象は同業同規模の民間企業であって、国ではない
2. 国家公務員等の旅費に関する法律は2025年4月1日施行の改正で、定額支給から実費支給（上限付き）へ移行した。
   「総理大臣は1泊◯万円もらえる」という言い方は、改正後は上限額の話であって、
   差額が手元に残る定額支給の話ではない

「国会議員に無理と言ってこいと返せる」という類の主張は、この改正以降さらに成立しにくい。

### 4-3. 明確に不可

- 実態のない出張の計上（泊まっていないのに宿泊料を受給する等）＝架空経費。仮装隠蔽なら重加算税
- 実費精算の建て付けのまま、乗っていない等級（グリーン車・ビジネスクラス）の料金を請求する
  → 上位等級を取りたいなら「◯◯相当額を定額支給」と規程に明記して定額運用にする。
  実費精算と定額支給を混ぜた瞬間に説明がつかなくなる
- 「税務署は突っ込まない」を根拠にした金額設定 — 調査官個人の力量への賭けであって制度上の安全性ではない

## 5. 法人と個人の資産分離

- 経営者保証を外して借りる。 公庫に経営者保証免除特例制度がある。
  経営者保証ガイドラインの要件を全部は満たさなくても、保証料の上乗せ等で解除を選択できる
  （経営者保証改革プログラム）。金利は上がるが、法人の失敗が個人資産に及ばない構造をつくれる
- 個人に落ちた資金は金融資産に変え、法人リスクから切り離す
- 個人側の所得控除（小規模企業共済・iDeCo等）と非課税枠（NISA）を併用する

ただし「法人に利益を残さない／赤字〜トントンで回す」設計とは両立しない。
赤字法人は格付けが下がり、そもそも保証なしで借りられなくなる。
財務健全性の回復が先、利益圧縮は後。 債務超過を抱えている局面では特にこの順序を守る。

---

## 6. 生活防衛ラインと必要利益の逆算

- 独立・撤退・拡大の判断基準を 年商で置かない。利益と手元資金で置く。
  利益が出ていても資金が乏しければ持たない
- 月次コストを全項目表にして常時把握する。税金と社会保険料を必ず含める。
  ここを曖昧にしたまま進めると資金がショートする
- 将来コスト（教育費等）を織り込み、多めに見積もる
- 必要利益 ＝ 生活費 ＋ 再投資原資。 拡大を続ける前提なら生活費だけを賄う水準では足りない。
  再投資原資は「1商品のOEMで消える額」を1単位として数えると現実的な線が出る

## 7. ポートフォリオの選択と集中（パレートのフラクタル）

ペリー・マーシャル『80対20の法則』。8割の売上を2割の商品が生む。
これはフラクタルで、2割の中の2割を見ると 全体の64%を4%が、50%を約1%が生む。

→ リソースが限られるほど、上位数SKUに集中して育て切るほうがリターンが大きい。
→ 実務的な使い方: 仕入条件の悪化（ロット増・原価上昇）の打診を受けたとき、
　 その商品の売上寄与順位を先に見る。下位ならその場で取り扱いをやめる判断材料になる。

## 8. CFO Agent としての出力ルール

1. 金額を断定しない。 「同業同規模比較で相当な水準を税理士と確定する」と必ず添える
2. クラス分けして出す — A: 適法で確立した実務／B: グレー（要件次第）／C: 採らない
   （関連知識「feedback_distinguish_risk_classes」（この配布版には未同梱。必要なら利用者に確認） に準拠）
3. グレーを出すときは制約付きの運用案とセットで、代表判断に上げる
4. 「◯◯なら突っ込まれない」という他者の体験談を根拠として採用しない。
   必ず通達・国税庁・裁判例の一次ソースに当てる（Rule 9・関連知識「feedback_verify_external_ai_claims」（この配布版には未同梱。必要なら利用者に確認））
5. 節税策を提案する前に、その会社の融資・格付け・債務超過の状況を先に確認する。
   利益圧縮と資金調達は正面から矛盾する

# Images 2.5への移行

確認日: 2026-09-09 / 配布版: 1.1.0

全画像生成・画像編集の標準対象をChatGPT Images 2.5に更新。「image2.5」と言わず「商品画像を作って」と依頼しても適用する。「image2」「imege2.5」も画像生成の意図として受け付ける。

## 公式確認と使い分け

OpenAIは2026-09-08、Images 2.5のCodexを含む提供開始を発表した。参照写真の保持、部分編集、複数回編集の一貫性、細部・質感、透明背景の改善が紹介されている。改善は商品の完全再現や文字の無誤字を保証しない。[公式発表](https://openai.com/index/introducing-chatgpt-images-2-5/)

| 利用方法 | 用途・扱い | 制約 |
|---|---|---|
| Codex組み込み画像生成 | 全画像依頼の標準。利用環境のimagegen手順を使う | この環境のツールにはモデル選択欄がなく、内部モデルはサービス管理 |
| API: gpt-image-2.5-flare | APIを明示選択した場合の通常用途候補 | 別途認証・料金・利用権限の確認が必要 |
| API: gpt-image-2.5-sunburst | APIを明示選択した場合の精密な制作・編集候補 | 精度を優先する用途。待ち時間との兼ね合いを確認 |

APIの正式IDは `gpt-image-2.5-flare` と `gpt-image-2.5-sunburst`。`gpt-image-2.5` という単独IDを推測して設定しない。Images APIとResponses APIの画像生成ツールを区別し、Responsesの会話モデルを画像モデルIDに置換しない。[画像生成APIガイド](https://developers.openai.com/api/docs/guides/image-generation)

APIの品質指定にはlow、medium、high、xhigh、maxがある。透過出力はbackground=transparentとPNG/WebPを使用する。これらのAPIパラメータがCodex組み込みツールにもあると解釈しない。旧モデルの入力忠実度・サイズ等の設定を一括流用せず、APIを使う際に現在のガイドで確認する。[画像生成APIガイド](https://developers.openai.com/api/docs/guides/image-generation)

料金は品質・サイズ・入出力等で変わるため、旧モデルの月間生成枚数や単価を移植しない。API課金とCodexの利用枠は別に扱う。[公式料金](https://developers.openai.com/api/docs/pricing)

## 実行ルール

1. 組み込み画像生成を使い、追加APIキーを求めない。実行できる画像依頼をプロンプト提示だけで終えない。
2. 編集対象を先に閲覧し、変更箇所と保持する商品・人物・文字・構図を具体化する。実在商品は権利を確認した実物写真を基にする。
3. 毎回、生成物を閲覧し、商品同一性・文字・指示への一致を確認する。透過は見た目だけでなくアルファを確認する。必要な文字組みは別途行う。
4. 保存先を指定されたら実際の生成ファイルからコピーして存在を確認し、依頼なく既存画像を上書きしない。
5. 組み込み機能が利用不可・失敗したら明示し、有料API・CLI・別モデルへ自動で切り替えない。
6. 正式発表、利用可能なツール、実際に使われたモデルIDを分けて報告する。プロンプトへ2.5と書くだけでモデルが固定されたとは扱わない。

ChatGPTのSketch・画像上コメント等が、このCodexツールにもあるとはみなさない。外部サービス上の2.5対応は、そのサービスの現在の提供状況を別途確認する。生成画像の来歴情報・透かしを除去する工程は追加しない。

## 検証と範囲

現行ルールとスキルの参照・配布ファイル・モデル表記を静的検査する。組み込みツールの引数にはモデル選択欄がないことを確認済み。今回の移行では画像生成の実行、内部モデルID、API実課金、2.5の画質・速度比較は未検証。

過去の生成実績・アーカイブ・旧リリースを2.5の実績へ書き換えない。システム同梱のimagegen実装は配布元が管理するため改変しない。ローカルの環境変数や認証設定は読み書きせず、明示的な旧モデル指定が残る場合はAPI実行時に利用者が見直す。

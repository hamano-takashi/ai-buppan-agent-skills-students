# 仕事から選ぶ

最初から全スキルを読む必要はありません。必要な作業から始めてください。

| 行いたいこと | 主に使うスキル | 用意するもの |
|---|---|---|
| 自分の事業の優先順位を決める | business-context / ec-commander / ec-solo | 商品、売上と費用、使える時間、目標 |
| 商品の選ばれる理由を整理する | cp-balance / pox-analysis / ec-brand-strategy | 想定顧客、商品仕様、自分で得た顧客の声 |
| Amazonの売上・広告を分析する | ec-amazon-analytics / ec-amazon-ad-analytics | 管理画面から取得した対象期間のレポート |
| 商品名や商品ページを見直す | ec-amazon-title-highlights / ec-amazon-strategy | 現在の表示内容、商品仕様、公式規定 |
| 商品画像を作る・直す | image-generation / ec-amazon-image-generator / ec-creative | 実物写真、用途、必要な文字、参考 |
| LINEやメールを作る | ec-engagement / comms-assistant / ec-crm-review-panel | 配信目的、相手、確認済みの事実 |
| 利益・在庫・仕入を見直す | cfo / ec-operations / supply-chain | 原価、手数料、在庫、販売数 |
| 作業を整理し、次回へつなぐ | pm / worklog / handoff-protocol | 期限、担当、成果物、未完了事項 |

各スキルの場所は [SKILLS_INDEX.md](../SKILLS_INDEX.md) から開けます。接続できる外部サービスがない場合も、ローカルの資料・下書きで進められる部分を先に進めます。

入力資料と結果の置き場所は [事業情報のひな形](../templates/project-context.md) で決めてください。氏名や注文番号を消したからといって、ほかの項目から個人が分からないとは限りません。必要な集計列だけを使います。

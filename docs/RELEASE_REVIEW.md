# 配布版の点検記録

版: 1.1.0 / 確認日: 2026-09-09

## 構成の方針

元の専門分野の手順を基に、受講生用の独立したファイル構成を作りました。内部リポジトリのGit履歴を移していません。

| 選択肢 | 利点 | 課題 | 採用 |
|---|---|---|---|
| 内部リポジトリを複製 | 構成をそのまま維持 | 履歴・個別情報・未配布ツールが混入する | 不採用 |
| 既存の公開配布版だけを使う | 既存の手順で導入できる | 今回の画像ルールや新しいスキルが反映されない | 不採用 |
| 配布対象だけを再構成 | 専門手順を残して個別情報と内部依存を除ける | 配布ごとに内容確認が必要 | 採用 |

## 修正内容

- 個人の保存先、会社・案件・内部製品の識別情報、社内の状況説明を除去・再構成。
- 会社固有の目標、AIモデル固定、合議体、未同梱のログ・分析スクリプトを共通運用に置換。
- 画像生成・画像編集の全依頼で組み込み画像生成を標準使用。
- 個別資料は local/ に分離し、外部送信・公開・課金・削除の承認範囲を明記。
- 依存しない導入手順、配布ファイルの一覧とハッシュ、検証ツールを追加。

## 配布対象外

| スキル | 理由 | 代わりの進め方 |
|---|---|---|
| pptx | Proprietary表示があり再配布条件が未確認 | 利用環境の正規の資料作成機能を使う |
| fe-exam-team | 個人の資格学習用 | 物販の目的に必要なスキルを選ぶ |
| ec-mmm-methodology | 未同梱の専用分析環境に依存 | ec-mmm-methodologyで分析設計を行う |
| trend-intel | 講師専用の定期処理 | trend-intelで必要な調査を行う |
| notion-meeting-tasks | 未同梱の音声取得・変換環境に依存 | 利用者自身の文字起こしを使う |

参照資料のうち私的な講座録画の観察記録、非公開の事業戦略・実測値、認証が必要な原文教材も同梱しません。

## 検証の範囲

ファイルの種類、個人パス・秘密らしい文字列、SKILL.mdの形式、参照リンク、配布一覧とハッシュを静的に確認します。秘密検査と独立した内容レビューを併用します。

全スキルを実アカウントに接続して実行したわけではありません。市場・法令・研究の数値、媒体仕様、外部ツールの現時点の動作、全受講生のWindows/Mac環境は未検証です。利用時に一次情報と権限を再確認します。

最終的な検証件数と実行結果は VERIFICATION.md を参照してください。
